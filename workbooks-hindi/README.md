## Update Protocol

1. शीर्षक, तारीख, URL, platform और version को प्रकाशित स्रोत या उपयोगकर्ता-पुष्ट जानकारी से सत्यापित करें।
2. एक ही लेख की चारों workbooks में अलग-अलग और scope-appropriate प्रविष्टियाँ रखें।
3. हिन्दी-विशिष्ट Constitution और Style Guide को इस system में स्वतः copy या merge न करें।
4. LOCKED, CURRENT / WORKING और DRAFT / PROPOSAL की अवस्थाओं को अलग रखें।
5. Publication ID और article sequence number को एक न मानें; किसी numbering scheme को canonical register से पुष्टि किए बिना न बनाएं।
6. किसी रिकॉर्ड में जानकारी अनुपलब्ध हो तो उसे स्पष्ट रूप से pending रखें; अनुमान को तथ्य की तरह न लिखें।
7. बदलाव के बाद सभी फाइलें दोबारा fetch करके सत्यापित करें।
